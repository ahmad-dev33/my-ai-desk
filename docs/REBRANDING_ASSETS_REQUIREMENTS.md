# متطلبات وأصول الهوية البصرية الجديدة (Branding & Rebranding Assets Specification)

يحتوي هذا الملف على قائمة تفصيلية بجميع الأصول البصرية (Images, Logos, Icons) التي تحتاج إلى تصميمها وتجهيزها لاستبدال العلامات التجارية القديمة وتحويل المنصة بالكامل إلى هويتك وماركتك التجارية المخصصة.

---

## 📂 المجلد المقترح لحفظ الأصول مؤقتاً في المشروع:
يُنصح بوضع جميع هذه الملفات فور تجهيزها داخل المجلد التالي في الـ Dashboard ليتسنى للمنصة قراءتها ونشرها تلقائياً:
`dashboard/public/brand/`

## 🛠️ كيف سيتم ربط هذه الملفات بالخدمات المختلفة تلقائياً؟

بمجرد تسليمنا هذه الملفات، سنقوم بضبط حاويات الـ Backend و Docker لقراءتها ونشرها كالتالي:

1. **لوحة تحكم الـ React Dashboard:**
   ستقوم تلقائياً بقراءة `dashboard/public/favicon.svg` و `dashboard/public/brand/logo.svg` وعرضها لجميع المستخدمين.

2. **نظام صندوق الوارد Chatwoot:**
   الحاوية الذكية الذاتية `chatwoot-brand` ستقوم تلقائياً بجلب الشعارات المرفوعة ونشرها داخل قاعدة بيانات Rails عند الإقلاع باستخدام السكربت التالي المعد برمجياً:
   * `LOGO` -> سيقرأ مسار الرابط `https://dashboard.domain.com/brand/logo.svg`
   * `LOGO_DARK` -> سيقرأ مسار الرابط `https://dashboard.domain.com/brand/logo-dark.svg`
   * `LOGO_THUMBNAIL` -> سيقرأ مسار الرابط `https://dashboard.domain.com/favicon.svg`

3. **نظام الأتمتة Typebot:**
   سيتم توجيهه لقراءة الـ Favicon الموحد وعرض اسم الهوية الجديدة على أزرار الدخول والنوافذ.

4. **نظام تسجيل الدخول Keycloak:**
   سنقوم بتثبيت ملفات `favicon.ico` و الشعار الرئيسي في مجلد ثيم تسجيل الدخول المخصص له (`/opt/keycloak/themes/unified/...`).

## 📝 ملاحظة للمصمم:
* **صيغ الـ SVG:** يفضل دائماً استخدام صيغ المتجهات الرسومية `SVG` للشعارات والأيقونات لأنها خفيفة جداً في التحميل ولا تفقد دقتها أو جودتها عند التكبير والتصغير وتعمل بكفاءة على شاشات الموبايل والكمبيوتر (Retina Displays).
* **اسم الماركة (`BRAND_NAME`):** يرجى تزويدنا بالاسم النصي الصحيح للماركة بدقة (باللغتين العربية والإنجليزية) ليتم استبداله في جميع النصوص والإيميلات الترحيبية الصادرة من النظام.
